갯바위 릴낚시 — 만화풍 에셋 v1
제작일: 2026-10-27

게임 적용용 이미지 48종. 각 PNG와 경량 WebP를 함께 제공합니다.
이 폴더는 에셋 패키지이며 현재 실행 중인 저수지 미니게임에는 아직 연결하지 않았습니다.

크기
- background-coast-day: 1080×1920, 불투명 바다 배경
- foreground-rocks: 1080×640, 투명 갯바위 전경
- equipment/rod-*: 384×1024, 기본/중간/강한 휘어짐
- equipment/reel-body, reel-complete: 512×512
- equipment/reel-handle: 256×256, 릴 손잡이 독립 부품
- fish/black-seabream-01~12: 각 256×256, 01~04 헤엄 / 05~08 몸부림 / 09~12 포획
- fish/black-seabream-icon: 128×128
- effects/: 각 256×256, 찌 착수/포획 물튀김/해안 포말/수면 반짝임, 각 4프레임
- ui/: 각 256×256, 던지기/챔질/릴 감기/회수, 찌 3상태, 크릴 미끼
- atlases/fish-4x3: 1024×768, 한 칸 256×256
- atlases/effects-4x4: 1024×1024, 한 칸 256×256
- atlases/controls-4x2: 1024×512, 한 칸 256×256

사용 방법
1. manifest.json에 경로, 이미지 크기, 권장 표시 폭, 기준점(anchor), 동작 순서와 FPS가 있습니다.
2. 애니메이션은 개별 프레임 교체 또는 atlases/ 시트의 256px 셀로 재생합니다.
3. 낚싯대 포즈를 바꿀 때는 각 파일의 anchor를 같은 손잡이 위치에 맞춥니다.
4. 낚싯줄, 릴 손잡이 회전, 이동 경로, 보상 숫자와 버튼 글자는 코드로 표현합니다.
5. 버튼의 나무판은 글자가 없는 상태입니다. 실제 화면에서 빗썸 고딕으로 글자를 올리세요.
6. 물 효과는 원본의 알파를 유지했습니다. 일반 합성으로 먼저 확인하고, 수면 반짝임은 필요 시 밝게 합성할 수 있습니다.
7. 생성형 동작 프레임은 포즈 변화용입니다. 실제 입력·물리 연동 시 이동/회전 보간과 위치 조절을 함께 사용하세요.

preview.html: 동작 및 합성 미리보기 (웹 서버에서 열기)
source/: 생성된 원본 6장. 실제 게임에서는 경량 WebP 및 정규화한 개별 이미지를 권장합니다.
validation.json: 출력 크기·투명 배경 검사 결과 및 파일 용량
PROMPTS.txt: 내장 image_gen 제작 프롬프트 기록

효과음
기존 낚시게임의 착수·물튀김·성공 소리는 재사용 가능합니다.
이번 패키지는 시각 에셋이며 새 파도/릴 전용 음원은 포함하지 않았습니다.
