# 어망 에셋 v1

- keepnet-button: 장비/미끼와 같은 계열의 원형 어망 버튼.
- keepnet-title: 흰색~하늘색 어망 제목.
- fish-row: 물고기 목록 카드 바탕. 이름/마릿수/최대 길이는 포함하지 않음.
- window: 기존 승인 창 테두리 재사용.
- close-button / close-icon: 기존 승인 닫기 버튼 재사용. 비례 유지.
- 각 부품 PNG 및 WebP. asset-sheet.png는 부품 6종 모아보기, 3열×2행.
- 기존 승인 물고기 8종은 ../fish-summary-v186/ 이미지를 재사용.
- 스크롤은 네이티브 UI로 구현할 예정. 제목/닫기는 고정, 목록 영역만 스크롤.
- preview.html은 에셋 조합 확인용 별도 페이지이며 실제 낚시게임에는 아직 연결하지 않음.
- 내장 imagegen 사용. 프롬프트 요약: 승인 어망 시안의 원형 keep-net 버튼과 흰색/하늘색 제목을 투명 PNG로 제작; 빈 바다색 카드 바탕에 동적 텍스트와 물고기 제외.

## 목록 텍스트 수정 v190

- 카드 안쪽 상하/좌우 여백 확보.
