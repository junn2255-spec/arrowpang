# 장비 에셋 패키지

- 이미지 생성: 내장 imagegen 사용. 승인된 장비창/버튼을 기준으로 투명 PNG 분리.
- 추가 에셋: 장착 중, 최고 단계, 업그레이드 완료, 잠김 배지. 금색/흰색 링과 별빛의 완료 효과 8프레임.
- 분리 PNG 21종, 효과 PNG 8장, 효과 시트와 manifest.json.
- preview.html: 부품 및 효과 미리보기.
- 물고기 8종: ../fish-animation-v1. 개별 프레임 64장과 8개 시트. quality-check.json에 여백/좌우 위치 검사 결과 기록.
- PNG는 알파 투명도 포함. 일부 미리보기 뷰어는 투명 영역의 RGB를 색 배경처럼 보여 줄 수 있으므로 실제 알파값 기준으로 확인.
- 동적 가격, 레벨, 보유 코인은 이미지에 포함하지 않고 게임 텍스트로 표시.
- 생성 지시 요약: ocean-blue fishing UI, transparent background, separate badges with Korean labels; eight sequential gold-white ring/sparkle frames in 4x2 grid, same center, generous margins.
