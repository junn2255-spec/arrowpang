# 1~6스테이지 고정 퍼즐 검증

2026-11-05. 수정 전 백업: ../../backups/before-strategy-stages-20261105

같은 색 자연 탈출 3개마다 보석 1개를 제거한다. 다른 색 탈출과 보드 교체는 미완성 기록을 초기화한다. 돌 충돌은 탈출로 세지 않는다. 목표 달성 시 즉시 종료하며, 화살표 소진 시 검증된 180도 대칭 후속 보드로 이어진다.

## 설계와 평가
- 1단계: 위쪽 화살표를 먼저 제거하면 오른쪽 화살표가 풀리는 두 층의 의존 관계.
- 2단계: 왼쪽 → 위쪽 → 오른쪽 순서의 세 층 구조. 서로 반대 방향은 행을 어긋나게 배치해 영구 교착을 피함.
- 3단계: 세 번 충돌해야 하는 돌이 선행 경로를 차단함.
- 4단계: 시계방향 회전과 돌 충돌을 조합하고 후속 보드에서도 같은 난이도를 유지함.
- 5단계: 아래쪽 → 왼쪽 → 위쪽 → 오른쪽의 네 층 의존 관계와 회전 우회로.
- 6단계: 추가 상향 화살표, 세 돌, 회전 우회로를 결합. 검증 경로는 37회로 제한 38회 안에 완료.

무작위 실험은 상태를 바꾸는 터치 중 무작위 선택과 탈출/돌 충돌 우선 선택의 두 정책을 각각 300회 실행했다. 상세값은 strategy-report.json에 있다. 실제 사람의 성공률을 의미하지 않는다. 계획 경로는 전 단계 성공하지만 무작위 선택은 단계가 올라갈수록 성공하기 어려웠다. 5~6단계의 최단 경로와 모든 해의 개수는 증명하지 않았다. 의존 깊이는 설계상 구조이며 자동 산출한 전체 그래프 지표는 아니다.

## 회귀 검증
- 전 단계 클리어, 보석 지급 횟수, 실행 취소 및 재실행 상태 일치.
- 후속 보드 풀이, 다른 색/보드 교체 기록 초기화, 회전 무한 루프 방지.
- 7~40스테이지 데이터는 백업과 동일.
- 모바일 크기 실제 브라우저에서 5초 힌트 및 1단계 클리어 전환 확인. 실행 오류 없음.
- UI·배경·에셋과 코인/집/미니게임 파일은 이번 작업의 변경 대상이 아님.

재현 스크립트는 프로젝트 상위 폴더의 test-strategy.mjs, evaluate-strategy.mjs, check-strategy-ui.cjs. 플레이어 분석 데이터의 외부 전송은 추가하지 않았다.
