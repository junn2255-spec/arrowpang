상단 현황 에셋 v1

1. status-progress: 업그레이드에 필요한 코인이 부족할 때 표시.
   고정 그림/문구: 스테이지, 보유 코인, 금화, 집, 집 업그레이드까지, 코인, 빈 게이지 바탕.
   게임에서 별도 표시: 스테이지 숫자, 보유 코인 숫자, 부족한 코인 숫자, 진행 게이지 채움.
2. status-upgrade-ready: 업그레이드 가능한 코인이 모이면 표시.
   고정 그림/문구: 스테이지, 보유 코인, 금화, 집, 집을 업그레이드 하세요!
   게임에서 별도 표시: 스테이지 숫자, 보유 코인 숫자.
3. 집 업그레이드 후 다음 단계의 필요 비용을 기준으로 status-progress 상태로 돌아가며
   집 업그레이드까지 [부족 금액] 코인으로 표시.

현재는 에셋 제작/검토 단계이며 게임에 적용하지 않았습니다.
제작 방식: 기본 이미지 생성 도구, 참조 이미지 편집.
프롬프트 요약: 참조의 돌/나뭇잎 테두리와 세 칸 구성을 유지하고 모든 숫자를 비우기.
진행 상태는 집 업그레이드까지 [빈 숫자 영역] 코인과 빈 회색 게이지를 포함.
가능 상태는 집을 업그레이드 하세요! 버튼과 집 그림을 포함.
