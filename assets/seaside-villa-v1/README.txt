나의 바닷가 별장 에셋 v1
게임 미적용. 검토용 제작 에셋.
배경 1종 / 건설 10단계 + 작은 아이콘10종 / 메인UI6종 / 추가UI6종 / 장식9종.
투명 시트는 manifest.json에 기록된 균일한 셀 단위로 자를 수 있습니다. 개별 PNG/WebP도 함께 저장했습니다.
